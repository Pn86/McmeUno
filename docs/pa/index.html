免责声明：本协议仅适用于 McmeUno 群组服务器，所有权归 McmeUno 管理团队所有。管理团队有权根据服务器运营、玩法调整、法律法规及其他实际情况，对本协议进行修改、补充或删除，修改后的协议自发布后立即生效。

第一条 玩家隐私协议
1.玩家进入并使用本群组服务器，即视为同意本群组服务器在保障服务器正常运行、安全管理及提升游戏体验的前提下，对必要信息进行收集、存储和使用。
2.本群组服务器仅收集与服务器运行相关的必要信息，不会主动收集与服务器服务无关的个人信息。
3.服务器可能收集的信息包括但不限于：
（1）Minecraft 游戏昵称；
（2）Minecraft UUID；
（3）登录、退出时间及在线记录；
（4）登录 IP 地址；
（5）玩家行为日志及系统操作记录；
（6）服务器运行所需的其他必要数据。
4.服务器可能依据玩家 IP 地址解析所属国家、省份或地区，仅用于服务器展示、统计分析、安全检测、风控及社交等功能，不会显示具体城市或更精确的位置。
5.玩家 IP 地址及其他敏感信息仅限管理团队在服务器维护、安全检测、违规处理、数据恢复及法律法规允许的情况下查看。
6.本群组服务器不会主动出售、出租、共享或向无关第三方提供玩家个人信息。
7.若因法律法规要求、司法机关依法要求、服务器安全受到严重威胁或其他依法应配合的情况，本群组服务器有权依法提供必要的信息。
8.服务器将采取合理措施保护玩家信息，尽可能防止数据泄露、非法访问、篡改或滥用；但因不可抗力、网络攻击、第三方服务异常等不可预见原因造成的数据异常，本群组服务器将在合理范围内积极处理。
9.为了实现跨服功能，本群组服务器内不同服务器之间可能同步玩家昵称、UUID、权限、称号、处罚记录、登录记录及其他必要数据。
10.玩家有权向管理团队咨询自身数据的使用情况，并可申请更正存在错误的数据。
11.请妥善保管自己的游戏账号，不得随意泄露账号信息、密码或将账号借予他人使用。
12.因账号共享、密码泄露、第三方软件、设备丢失或其他玩家自身原因造成的一切损失，由玩家自行承担。

第二条 玩家游玩协议
1.本协议适用于 McmeUno 群组服务器内所有服务器，无论服务器玩法、管理团队、经济系统或游戏模式如何变化，所有玩家均应遵守本协议。
2.各子服务器可根据自身玩法制定独立规则，玩家进入对应服务器时，应同时遵守本协议及对应服务器规则；子服务器规则仅在对应服务器内生效。
3.玩家应遵守服务器所在地法律法规及自身所在地法律法规，不得利用本群组服务器从事任何违法犯罪活动。
4.严禁传播、发布或讨论违法、淫秽色情、赌博、毒品、暴力恐怖、诈骗、极端主义、仇恨歧视以及其他违反法律法规或公序良俗的内容。
5.严禁以任何形式攻击服务器，包括但不限于 DDoS、CC、恶意刷包、漏洞攻击、恶意扫描、非法连接、恶意消耗服务器资源及其他影响服务器正常运行的行为。
6.严禁故意利用服务器漏洞、插件漏洞、游戏漏洞、经济漏洞、复制漏洞或其他异常机制获取非法利益；发现漏洞应及时向管理团队反馈，不得故意隐瞒、传播或利用。
7.允许玩家使用辅助模组、优化模组、便捷功能模组以及不会明显影响服务器公平性的轻量辅助工具；但严禁使用高强度外挂、自动化作弊程序、恶意辅助工具或任何可能破坏游戏平衡、影响其他玩家正常游玩、绕过服务器检测或对服务器安全造成威胁的软件、硬件及相关设备。具体允许范围以各子服务器规定为准。
8.严禁利用脚本、机器人、自动化程序或其他无人值守方式长时间替代玩家进行游戏、刷资源或执行其他可能影响服务器公平性的行为，特殊玩法或服务器另有规定的除外。
9.严禁恶意骚扰、辱骂、人身攻击、恶意举报、刷屏、诈骗、散布谣言、煽动他人或其他影响社区环境的行为。
10.严禁冒充管理团队成员、官方人员或其他玩家，不得伪造身份、发布虚假公告或传播误导性信息。
11.未经管理团队许可，不得冒用 McmeUno 群组服务器名义开展活动、发布公告、建立官方群组、募集资金或代表服务器发表声明。
12.严禁传播恶意程序、病毒、木马、非法链接、危险二维码、违法文件及其他可能危害玩家设备或服务器安全的内容。
13.未经允许，不得利用本群组服务器进行违法交易、账号买卖、虚拟物品诈骗、洗钱、非法商业经营或其他影响服务器正常运营及公平性的行为。
14.玩家应尊重其他玩家及管理团队，不得恶意干扰服务器活动、官方赛事、服务器测试、维护工作及其他正常运营安排。
15.对于严重违规行为，管理团队有权根据实际情况采取限制聊天、限制功能、限制进入指定服务器、限制进入整个群组服务器、临时封禁、永久封禁、清除部分或全部游戏数据等处理措施。
16.本群组服务器不同子服务器可能拥有不同玩法、经济系统、管理团队及处罚标准；对于严重违规行为，处罚可根据违规性质同步至多个服务器甚至整个群组服务器。
17.本协议未明确规定但足以影响服务器公平、正常运营、玩家体验或服务器安全的行为，管理团队有权根据实际情况进行认定并采取相应处理措施。
18.本协议生效于所有服务器，但是根据第四条其他服务器协议的内容会覆盖该条内容协议

第三条 玩家赞助付费协议
1.本服务器的 水晶 货币是服务器唯一官方付费货币，其他子服务器付费货币均为非官方货币，不受McmeUno群组服务器直接管理
2.未成年用户赞助请在监护人的指导同意下进行，根据国家新闻出版署发布的《关于进一步严格管理，切实防止未成年人沉迷网络游戏的通知》，我们的赞助要求是：
（1）未满12周岁的用户无法进行游戏赞助；
（2）12周岁（含）以上未满16周岁的用户，单次赞助上限50元人民币，每月赞助上限200元人民币；
（3）16周岁（含）以上未成年用户，单次赞助上限100元人民币，每月赞助上限400元人民币。
3.赞助后玩家若年满18周岁（含）可以在赞助后10分钟内申请使用正当理由直接退款未消耗的水晶部分，如果已消耗则不能退款
4.赞助后玩家若不满18周岁可以在赞助后30天内申请使用身份证件或户口本作证并让监护人与服务器管理组取得联系并提交正当理由，审核后即可未成年退款全款，但是退款后服务器将封禁这个账户并保存本次的提交信息
5.所有赞助商品仅限于个人、个人团体(线下朋友亲友)使用，严禁在未经允许下转让、赠送、出借、给予他人，如需转让、赠送、出借、给予他人需在服务器管理组报备并提交证明
6.严禁二次出售或利用赞助物品产生其他盈利关系的所有赞助商品，一旦发现没收并封禁且不得退
